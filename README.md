# ☁️ Microsoft Azure Virtual Machine Placement Optimization

## 📌 Project Overview
This repository contains the optimization model and framework developed to solve the Virtual Machine (VM) placement problem in cloud data centers. The goal is to achieve balanced load distribution while strictly adhering to Quality of Service (QoS) and Service Level Agreement (SLA) constraints.

🤝 **Industry Collaboration:** This academic project was developed as part of the Mathematical Modelling course, under the direct industry mentorship of Barbaros [Soyadı] (Azure Solutions Architect Expert at Microsoft).

## 📊 Project Artifacts
* 📄 **[View the Project Poster (PDF)](Microsoft_Azure_Optimization_Poster.pdf)** - A comprehensive visual summary of our mathematical model, methodology, and simulation results.

## 🛠️ Tech Stack & Methods
* **Optimization Engine:** GAMS, CPLEX
* **Modeling Technique:** Mixed-Integer Programming (MIP)
* **Performance Evaluation:** Custom Simulation Framework

## 🚀 Key Achievements & Results
* Formulated a robust deterministic optimization model to handle various cloud demand scenarios.
* Achieved **balanced load distribution** across servers, preventing localized bottlenecks.
* Successfully maintained a **0% QoS violation rate** across all tested demand scenarios, ensuring strict SLA compliance.
* Built a simulation framework to systematically evaluate scalability and resource utilization performance.

## 💼 Business Value
Optimal VM placement directly impacts cloud operational costs and energy consumption. This project demonstrates the ability to translate high-level business constraints (SLAs) into rigorous mathematical models, a highly valuable skill for **Cloud Capacity Planning, Operations Research, and Data Center Analytics.**
